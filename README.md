# Data Analysis with Python

This repository contains my coursework, labs, and projects for the **Data Analysis with Python** course by IBM. The focus of this work is on using Python to import, clean, explore, visualize, and analyze real-world datasets, followed by developing and evaluating machine learning models.

## 🛠️ Tech Stack & Tools

* **Language:** Python 3.x
* **Data Analysis:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Statistical Analysis:** SciPy
* **Machine Learning:** Scikit-learn
* **Environment:** Jupyter Notebook
* **Database:** SQLite

## 📂 Repository Structure

### Importing Data Sets

* **Objective:** Working with different data sources, importing datasets, inspecting their structure, and performing initial analysis using Pandas and NumPy.

### Data Wrangling

* **Objective:** Cleaning and preprocessing datasets by handling missing values, correcting data types, normalizing data, binning, and transforming categorical variables.

### Exploratory Data Analysis

* **Objective:** Discovering patterns and relationships within datasets using descriptive statistics, grouping, correlation analysis, and data visualization.

### Model Development

* **Objective:** Developing predictive models using linear regression, multiple linear regression, polynomial regression, and Scikit-learn pipelines.

### Model Evaluation

* **Objective:** Evaluating and refining machine learning models using metrics such as R² and Mean Squared Error, while addressing overfitting and underfitting.

### Final Project

* **Objective:** Applying the complete data analysis workflow to a real-world dataset, from data wrangling and exploratory analysis to model development and evaluation.
